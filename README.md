# Swift Travel App

A travel app built in Swift (iOS) to help users explore destinations, plan trips, and manage itineraries.

## Features

- Browse and search travel destinations  
- View details about a destination (photos, description, location)  
- Create and manage travel itineraries  
- Save favorite destinations  
- Interactive map view

## Requirements

- iOS 14.0+ 
- Xcode 
- Swift

## Installation

1. Clone the repository  
   ```bash
   git clone https://github.com/VedangBhagare/Swift-Travel-App.git
   cd Swift-Travel-App
   ```

2. Open Project in XCode
   open veds_travel.xcodeproj

3. Build and run on simulator or device

## Architecture & Design

MVC 
Core modules (Models, Views, Controllers)
Networking — API client, endpoints, parsing
Data persistence — Core Data, local JSON, caching
